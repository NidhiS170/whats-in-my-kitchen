# whats-in-my-kitchen
A Java program that finds recipes based on ingredients users have available.
# What's in My Kitchen?

## Features
- Enter ingredients you have available.
- Search for recipes using TheMealDB API.
- Display matching recipes.
- View recipe ingredients and cooking instructions.

## Future Features
- Save favorite recipes.
- Filter recipes by cuisine or meal type.
- Generate grocery lists for missing ingredients.

## Technologies
- Java
- TheMealDB API
- Java HttpClient
- JSON library (org.json)

## How It Works
1. User enters available ingredients.
2. Program sends a request to TheMealDB API.
3. API returns matching recipes.
4. Program displays the recipes.
5. User selects a recipe to view its ingredients and instructions.
